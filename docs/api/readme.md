# API reference

This section documents the exported `github.com/qlustra/glove` surface directly.

It is intentionally reference-oriented:

- [Driver API](driver.md) covers `Bin`, `CompileOptions`, `Driver`, `Compile`, `New`, and driver methods.
- [Command API](command.md) covers `Command`, `RunOptions`, `Result`, `Runner`, and `ExecRunner`.

For the conceptual model, start with the [usage docs](../usage/model.md). For end-to-end layouts, use the [examples](../examples/git.md).
